SolarPak KPI Dashboard — Replit Build Prompt
Build a full-stack KPI dashboard web app for SolarPak, a solar nonprofit operating in Pakistan. The app should feel premium and data-driven. Use the Impact Labs design system for all colours, typography, and visual styling — Replit has access to this. Think bold data visualisation, clean surfaces, and a modern nonprofit impact report aesthetic. All data is hardcoded in a central data.js config file. No backend required.

Tech stack
React (Vite) · Tailwind CSS · Recharts · React Router · Framer Motion · all data in data.js

App structure
The app has a persistent sidebar with SolarPak branding and colour-coded team indicators. On mobile the sidebar collapses to a bottom nav. All pages share a year selector toggle (Year 1 / Year 2 / Year 3) in the top bar that switches all data across every view simultaneously. All KPI actuals entered by the user persist in localStorage.

Pages
1. Overview (/)
Top stat bar with four large metric cards: total families served to date, total CO₂ avoided, total funds raised, active volunteers. Below that, a progress ring or bar chart per team showing overall KPI completion % for the selected year. A health-at-a-glance row shows one RAG (red/amber/green) status pill per team — green ≥90% of target, amber 70–89%, red below 70%.
2. Team KPI Tracker (/teams)
Tab or sidebar selector for each of the 6 teams. Each team view shows its KPIs as cards containing: KPI name, Year 1/2/3 target, an editable Actual input field, a progress bar filling toward the target, and a % completion badge colour-coded by RAG status. Actuals persist in localStorage.
3. Risk Heatmap (/risks)
An interactive 5×5 grid — X axis is Impact (Negligible to Severe), Y axis is Likelihood (Rare to Critical). Cell background colours: score ≥15 = red, ≥8 = orange, ≥4 = amber, <4 = green. Each of the 9 risks is plotted as a coloured dot on the grid at its correct likelihood/impact coordinate. Hovering a dot shows a tooltip with: risk name, category, score, and mitigation note. Below the grid is a sortable risk register table with columns: Risk, Category, Likelihood, Impact, Score, Priority, Mitigation. Category colour coding: Operational = coral, Financial = purple, Reputational = blue, People & Volunteers = teal.
4. Impact Summary (/impact)
Cumulative families served bar chart across Y1/Y2/Y3. CO₂ avoided area chart. Household energy saving % line chart (20% → 35% → 50%). Fundraising stacked bar split by individual donors, events, and grants per year. A donor pipeline funnel: Reached → Approached → Committed → Retained.
